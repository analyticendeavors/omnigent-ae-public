# Public allowlist for scripts/leak-scan.py (added 2026-10-28; see docs/LEAK-SCAN.md).
#
# One entry per line: <class> <pattern> [path-glob] # reason
#   - A pattern is a literal (matched case-insensitively against the matched text, with * and ?
#     wildcards), a /regex/, or sha256:<hex>, the sha256 of the lower-cased matched value.
#     Run the scan with --hash-hits to get the hex for a hit; the value is never printed.
#   - Prefer sha256 for a real value: this file is public, and a literal here is one more copy.
#     The scanner refuses a regex that matches almost anything (a whole class for a file).
#   - The optional path-glob limits the entry to matching file paths (* crosses /).
#   - A binary entry is an exact path: 'binary <path> # reason' (no glob, no wildcard).
#   - The reason is required, and must not name a private value: this file is checked against
#     the private denylist, and a match anywhere in it (comments included) is a scan failure.
#   - commit-identity entries list author and committer e-mail addresses that may reach the
#     public fork besides the built-in noreply and bot addresses.
#   - The allowlist never clears denylist, secret or private-key hits.
# A sha256 of a short or guessable value (an address, a user name) can be reversed by trying
# candidates; it hides the value from a search, not from a determined reader. Real values are
# marked DECISION below so each gets replaced, then its line deleted.
#

# .example/.invalid/.test/.localhost names, noreply addresses, systemd unit names,
# git@<host> clone URLs, placeholder names (box, tailnet, demo, user, ...) in host names and
