# Security policy

## Supported versions

Only the current release is supported: the latest `ae-v*` tag on this repository.

## Reporting a vulnerability

Report it privately. Do not open a public issue or pull request for a security problem.

Use GitHub's private advisory form:
https://github.com/analyticendeavors/omnigent-ae-public/security/advisories/new
(the Security tab, then "Report a vulnerability"). If you cannot use GitHub, email
info@analyticendeavors.com.

Please include what you found, how to reproduce it, and which version or tag you tested. Problems in OmniGent itself, outside the patches in `patches/`, belong with the upstream project.

## What to expect

We acknowledge a report within 5 business days, and within 30 days we either ship a fix or tell you the plan and its timing. We credit reporters in the advisory unless you ask us not to.
