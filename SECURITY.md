# Security policy

## Supported versions

Only the current release is supported: the latest `ae-v*` tag on this repository.

## Reporting a vulnerability

Report it privately. Do not open a public issue or pull request for a security problem.

Contact: info@analyticendeavors.com

Please include what you found, how to reproduce it, and which version or tag you tested. Problems in OmniGent itself, outside the patches in `patches/`, belong with the upstream project.
